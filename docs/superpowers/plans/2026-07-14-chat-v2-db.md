# Chat v2 Phase 2 · DB 落库 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 聊天强制登录；topics/messages 落 PostgreSQL；去掉 localStorage 分桶；支持话题重命名与删除。

**Architecture:** Drizzle `chat_topics` + `chat_messages`；API 仿 `knowledge-bases`（`getAuthenticatedUserId` + Model(userId)）；前端 TopicSidebar/ChatPage 改 fetch；流式仍走 `/api/chat`，结束后 PUT 全量消息。

**Tech Stack:** Drizzle、Better Auth、Next.js App Router、Vitest、现有 `@/libs/auth/get-session-user`。

**Spec:** `docs/superpowers/specs/2026-07-14-chat-v2-db-design.md`
